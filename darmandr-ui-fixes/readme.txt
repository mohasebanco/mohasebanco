=== Darmandr UI Fixes ===
افزونه جداگانه برای سایت درمان‌دکتر. فایل مادر قالب یا افزونه‌های چتی و کریسپ را تغییر نمی‌دهد.

کارها:
1) دکمه‌های تماس شناور سمت چپ و دکمه بازگشت به بالا سمت راست را روی موبایل بالای منوی پایین می‌آورد.
2) هنگام باز بودن گفتگوی کریسپ همان دکمه‌ها را پنهان می‌کند تا روی صفحه شلوغ نشود.
3) زبان ویجت کریسپ را قبل از لود روی fa می‌گذارد تا دیالوگ شماره تلفن و بقیه متن‌ها فارسی شوند.
